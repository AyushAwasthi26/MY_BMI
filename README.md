## ⚕️ About the Project:

The BMI Calculator is a health-focused web application that helps users quickly calculate their Body Mass Index and understand their health status. Built with modern web technologies and featuring animated visual elements, this tool provides both accurate calculations and an engaging user experience.

Here's how it works:

Enter Your Metrics: Input your weight in kilograms and height in centimeters using the clean, intuitive form.

Instant Calculation: The application processes your data using the standard BMI formula and provides immediate results.

Health Categorization: Get your BMI value along with your health category (Under Weight, Normal, Over Weight) based on WHO guidelines.

Visual Feedback: Enjoy animated floating particles and smooth interactions that make health tracking more engaging.

The project demonstrates form validation, mathematical calculations, and modern CSS animations while providing a practical health tool for everyday use.

## ✨ Features:

Accurate BMI Calculation: Uses the standard BMI formula (weight/height²) with precise decimal calculations.

Health Status Categorization: Automatically categorizes results into Under Weight, Normal, and Over Weight based on WHO standards.

Input Validation: Comprehensive validation ensuring only valid positive numbers are accepted.

Animated UI Elements: Floating particle animation system with staggered timing for visual appeal.

Responsive Design: Clean, card-based layout that works seamlessly across all device sizes.

Real-time Results: Instant calculation and display without page refresh or loading delays.

User-friendly Interface: Clear labels, placeholders, and error messages for optimal user experience.

## 💻 Tech Stack:

Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Custom CSS with modern card design and particle animations

Typography: Clean, readable fonts with proper hierarchy

Layout: Responsive design with flexbox/grid systems

Animations: CSS keyframe animations for floating particles

## 🎯 How to Use:

Using the BMI Calculator:

Open the Application: Load the HTML file in your web browser

Enter Weight: Input your weight in kilograms (supports decimal values like 70.5)

Enter Height: Input your height in centimeters (supports decimal values like 175.2)

Calculate BMI: Click the "Calculate BMI" button to process your data

View Results: See your BMI value and health category displayed immediately

Recalculate: Change your inputs and calculate again as needed for tracking progress

## 📊 BMI Categories:

The calculator uses standard WHO BMI categories:

Under Weight: BMI less than 18.6
- May indicate insufficient body weight for height
- Consider consulting healthcare provider for guidance

Normal: BMI between 18.6 and 24.9
- Indicates healthy body weight for height
- Associated with lower risk of weight-related health issues

Over Weight: BMI greater than 24.9
- May indicate excess body weight for height
- Consider lifestyle modifications and healthcare consultation

Important Note: BMI is a screening tool and doesn't directly measure body fat or overall health. Consult healthcare professionals for comprehensive health assessment.
